## Skyline 737 — Boeing 737-900 flight simulator

[`b737sim/`](b737sim/) contains a browser flight simulator, in the style of Infinite Flight,
built around operating the Boeing 737-900: 6-DOF flight model, 737NG autopilot with
autoland, PFD/ND/EICAS glass cockpit, GPWS callouts, 20 airports with lighting and PAPIs,
day/night, weather, and keyboard/gamepad/touch controls.

```bash
cd b737sim && python3 -m http.server 8000   # open http://localhost:8000
```

See [b737sim/README.md](b737sim/README.md) for features, controls and a first-flight guide.
