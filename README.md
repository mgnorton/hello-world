## Skyline 737: Boeing 737-900 simulator based at KDFW

[`b737sim/`](b737sim/) is a flight simulator in the spirit of Infinite Flight, built around
operating the Boeing 737-900 over real North Texas terrain, with FAA navigation aids and
procedures and NOAA-based dynamic weather. It is written in TypeScript and renders with WebGL.

```bash
cd b737sim && npm install && npm run dev   # http://localhost:8000
npm test                                   # headless flight tests
```

See [b737sim/README.md](b737sim/README.md) for the test link, features, controls and data sources.
